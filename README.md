# 琢巧小栈 · 开源工具

说一句话,agent 去做完。每个工具一个目录、一支视频;读各目录 `AGENTS.md` 即可部署。

工具页(含视频与一键复制):https://zhuoqiao.top/tools/

### [PDF 转 Markdown](pdf2md/)
把 PDF 变成 agent 读得懂的文字,公式表格都留着。

[![演示视频](https://zhuoqiao.top/tools/pdf2md/poster.jpg)](https://zhuoqiao.top/tools/pdf2md/)

### [论文下载](paper-download/)
给 DOI、链接或题名,拿到核对过的全文 PDF。

[![演示视频](https://zhuoqiao.top/tools/paper-download/poster.jpg)](https://zhuoqiao.top/tools/paper-download/)

### [论文调研](paper-survey/)
说一个大概方向,一两分钟拿到一页文献综述和推荐清单。

[![演示视频](https://zhuoqiao.top/tools/paper-survey/poster.jpg)](https://zhuoqiao.top/tools/paper-survey/)
