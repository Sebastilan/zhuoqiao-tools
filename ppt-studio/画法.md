# 画法(给画手 agent:一页一页做,每页照这个流程走)

分工:**人给讲稿和必要素材(照片、徽标、数据),你负责排版和画面**。讲稿是这一页「要说的话」,你的活是让观众三秒看懂这句话。

## 输入与输出
- 输入:每页一份 `输入/P<n>.txt`(章名 + 页标题 + 讲稿;有上屏要求的照写)。用户只给了一整篇稿子时,先和他一起切成页,每页一句核心意思。
- 选风格:`styles/lecture/`(讲座版)或 `styles/professional/`(专业版),**先通读该风格的 `spec.md`,再看 `samples/` 里的 JPG 学味道**(不照搬构图)。
- 输出:`页/P<n>.html`,每页一个 `<section class="slide B-s" data-title="…">…</section>` 片段,画布 1920×1080,讲稿逐字放 `<aside class="notes">`。

## 每页四步
**a 点子(先想清楚再动手)**:写 `点子/P<n>.md`,三段——
- `一句话:` 这页要让观众记住什么(从讲稿提炼,别偏题、别编数字)。
- `画面:` 用什么画面表达这句话:有哪些元素、谁在做什么、关系怎么画(先后/并行/对比/回头)、主角在哪、占画面多少。
- `上屏文字:` 逐条列出要上屏的短句(一般 ≤40 字)。

然后**换一个干净上下文**(新会话或子 agent)按下面五问审点子,不过就改,最多 2 轮:
1. 一句话是否抓住讲稿核心,不偏题、不添讲稿没有的事实/数字/名称?
2. 画面是否真在表达这句话(有叙事、有因果/先后/对比),而不是装饰或把文字框堆成图?
3. 上屏文字是不是讲稿提炼的短句,总字数合理?
4. 画得出来吗(元素不过多、关系清楚)?
5. 观众 3 秒内能看懂这页想说什么吗?

**b 画**:按点子手写 SVG 主图 + HTML 文字,写成 `页/P<n>.html`。只用该风格 `tokens.css` 的类与色板;其余样式写在页内 `<style>`,类名加页号前缀(如 `.P3-box`)。

**c 渲染自查(必须)**:
```
python3 tools/render_check.py 页/ --out 自查/ --css styles/<风格>/tokens.css --deck
```
脚本报字数、图占比、文字相交/越界、字号、色板;❌ 必须清零。**然后逐张亲眼看 `自查/P<n>.png`**(你没有看图能力就请用户看),对照:
1. 遮住文字只看画,能不能猜出这页大意?
2. 有无字压框、字压图、标签离开它指的东西、元素重叠遮挡?
3. 线宽、配色、人物造型是否合规范,有没有幼稚夸张的表情?
4. 留白、重心、图文比例是否像样例?

不过关就改,最多重画 4 轮。

**d 独立评审(交付前)**:让**另一个模型或新会话**只看 `自查/*.png`(不告诉它出自谁),按下表打分,按它写的「最大毛病」逐条改一轮。
- 模板脸信号(看到一条记一条):渐变横幅/按钮;同款圆角白卡一张接一张;「浅色方块+小图标+粗标题+灰说明」三件套重复;emoji 当图标;彩色胶囊标签;等宽功能卡网格;处处同间距同字号无焦点;大圆角软投影的 SaaS 感;空洞口号;主角(内容)小、装饰大;字没有层级;通篇都是字;像半成品的占位块(专业版有意留的照片占位除外)。
- 五项各 1–5 分:风格(贴不贴规范)、层次(3 秒看懂、有一个焦点)、主角(内容是主角)、完成度(对齐、线宽一致、无压字出界)、去模板味(有一处让人记住的设计决定)。
- 过 = 信号 ≤1 且五项都 ≥4。每页写最大毛病一句、改法 ≤3 条。

## 收尾
- 整稿:`自查/deck.html` 是翻页整稿(→/空格 下一步,N 备注,F 全屏,P 演讲者视图),单文件离线可放映。
- 写 `完成.md`:每页的一句话、画了几轮、自查与评审最后结果、你认为没做好的地方(别藏)。

## 常见坑
- 用 `feDisplacementMap` 抖线的滤镜须写 `filterUnits="userSpaceOnUse"`,否则竖直细线会被裁掉。
- 标题与副句的 `top` 至少差「字高×1.2」,否则互相压住。
- 中文标点用全角;脚本对半角只报警告,落盘后看图确认。
- 图占比脚本对「铺满整页的一张 SVG」会报 100%,以目测为准(讲座版目标 55–70%)。
- 整页底色矩形/大色块放在文字之前(或给文字更高 z-index),否则会盖住全部文字。
- 同一页里的角色造型保持一致:先写一个画角色的函数/`<symbol>`,各处复用,只改姿态与表情。
- 不要为了好看删掉讲稿里的用途说明(卡片页每张卡保留「是什么 + 一句用途」)。
- 大面积实色块不出血、不压满画面;同类元素(如五级台阶)配色要有规律。
- 讲稿里没给的网址、数字、出处不要编;推断要在 `完成.md` 里写明。
- 封面上的单位、姓名照用户给的写;做公开样例时用【单位名称】【姓名】这类占位。
- 页内样式要写成 `.B-s .P3-x` 这样带 `.B-s` 前缀,才压得过基座里的 `.B-s .B-title` 等规则。
- 两行大标题行高 ≥1.18,否则自查会报文字相交。
- 纯文字页、数字页(本来就没有主图)在 section 上标 `data-kind="text"`,表格页标 `data-kind="table"`;不标会被「图占比 < 22%」判不过。照片占位块用内联 SVG 灰矩形,脚本才认作图。
